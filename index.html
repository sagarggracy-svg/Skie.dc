❓ Got Questions?

Frequently Asked Questions

How do I set up 𝐒𝐤𝐢𝐞 in my server? +
Setting up 𝐒𝐤𝐢𝐞 is 100% handled directly through your Discord server! Once invited, you can configure modules using automated commands like /logs setup (auto-creates an admin-only log category) or /jail setup (auto-creates the isolated #jail channel). All commands and how they work can be easily understood either right here on this Web Dashboard or by typing /help in any server channel.
Is Skie completely free to use? +
Yes, Skie is 100% free with zero paywalls. All core features—Anti-Nuke, 24/7 music streaming, disciplinary jail, audit logging, and temporary voice channels—are available to every community at no cost.
How does the Anti-Nuke defense system work? +
Skie monitors audit logs using a sliding-window tracker (e.g. 10 seconds). If a user exceeds safe thresholds (such as deleting 3 channels or banning 3 members), Skie immediately strips their administrative roles (quarantine) or bans them, while pinging server staff in your alert channel.
Does the music bot stay 24/7 in voice channels? +
Yes! Using /music 247, the bot locks permanent stay mode and continuously plays high-fidelity audio streams without automatically disconnecting when channels go idle.
How does the Disciplinary Jail restore roles? +
When you run /jail user, Skie records all of the member's current roles into its persistent database before stripping them and assigning @Jailed. When the user is unjailed (manually or via sentence timer), all original roles are automatically re-applied!
